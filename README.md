# 形状迷宫生成器 MVP

一个零依赖、纯浏览器运行的迷宫生成器。整体轮廓支持三角形、正方形和圆形，内部使用规则方格生成拥有唯一解的迷宫。

## 运行

```bash
npm start
```

然后访问 <http://localhost:8000>。

也可以使用任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

## 测试

```bash
npm test
```

## 当前功能

- 三角形、正方形、圆形迷宫轮廓
- 简单、中等、困难三级密度
- 随机种子与结果重现
- 可选中心终点模式：从外部入口走到图形中心
- 可选贯穿模式：从底部入口走到顶部出口
- 正确路线显示
- SVG 下载
- SVG 水印包含随机种子、形状、尺寸、终点模式和算法版本，便于复现
- 在线闯关：支持方向键、WASD 和触屏方向按钮
- 闯关计时、步数、撞墙次数和行走轨迹
- 经典闯关模式：从入口直接到达中心终点或外部出口
- 取宝逃生模式：先取得中心宝物，解锁出口后再逃出迷宫

所有生成都在浏览器本地完成，不上传数据，也不需要后端或数据库。
