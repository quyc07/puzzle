# 形状迷宫生成器 MVP

一个零依赖、纯浏览器运行的迷宫生成器。整体轮廓支持三角形、正方形和圆形，内部使用规则方格生成拥有唯一解的迷宫。

## 运行

```bash
npm start
```

然后访问 <http://localhost:8000>。

也可以使用任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

## 测试

```bash
npm test
```

## 当前功能

- 三角形、正方形、圆形迷宫轮廓
- 简单、中等、困难三级密度
- 随机种子与结果重现
- 可选中心终点模式：从外部入口走到图形中心
- 可选贯穿模式：从底部入口走到顶部出口
- 正确路线显示
- SVG 下载

所有生成都在浏览器本地完成，不上传数据，也不需要后端或数据库。
